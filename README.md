# Kvit

Mesečni obračun stroškov skupnega življenja: fiksni znesek na mesec, od
katerega se odštejejo nakupi in plačila, stanje se prenaša iz meseca v mesec.
Next.js 16 + Supabase, deploy na Vercel.

```bash
npm install
cp .env.example .env.local   # vpiši Supabase URL in anon ključ
npm run dev                  # http://localhost:3007
```

Podrobnosti v `CLAUDE.md`.
